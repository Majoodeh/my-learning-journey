## Controlled Components:

Form Elements: `<input>, <textarea>, <select>`, they are used to collect user input in a web application. In React, these form elements can be either controlled or uncontrolled components.
A controlled component is a form element whose value is controlled by React state. This means that the value of the form element is set by the state of the component, and any changes to the value of the form element are handled by updating the state.
Here's an example of a controlled component using an `<input>` element:

```jsx
import React, { useState } from "react";
function ControlledInput() {
  const [value, setValue] = useState("");

  const handleChange = (event) => {
    setValue(event.target.value);
  };

  return (
    <div>
      <input type="text" value={value} onChange={handleChange} />
      <p>You typed: {value}</p>
    </div>
  );
}
export default ControlledInput;
```

In this example, the value of the `<input>` element is controlled by the value state variable. When the user types in the input field, the handleChange function is called, which updates the value state variable with the new input value. The updated value is then reflected in the input field and displayed below it.

- The importance of `value` and `onChange` props:
  - The `value` prop sets the current value of the input field to the value of the state variable. and we can use this to display the current value of the input field in other parts of the component, or to perform validation on the input value.
  - The `onChange` prop is an event handler that is called whenever the user types in the input field. It updates the state variable with the new input value.

`<form>`: by default, when a form is submitted, _`the browser will reload the page`_. In React, we can prevent this default behavior by using the `event.preventDefault()` method in the form's `onSubmit` event handler.

#### !NOTE:

event: It is an object that contains information about the event that occurred. When something happens on the web page (click, keypress, mpuse move,etc.), the browser takes a snapshot of everthing happening at that moment and creates an event object.

by passing the event object to the event handler function, we can access information about the event, such as the target element, the type of event, and any additional data associated with the event.

most common used event properties:

- event.target: It refers to the element that triggered the event. For example, in a click event, event.target would be the element that was clicked.
- event.type: It indicates the type of event that occurred, such as "click", "keydown", "mouseover", etc.
- event.preventDefault(): It is a method that can be called on the event object to prevent the default behavior of the event. For example, in a form submission event, calling event.preventDefault() would prevent the form from being submitted.

- just in short and easy words: event is an object that is created by the browser when something happens on the web page, and it contains information about that event.

- ?? there is still one question: how do we get access to the event object in react?
- In React, when you define an _event handler function_, the event object is automatically passed as the first argument to that function. You can then use this event object to access information about the event that occurred.
- In the example above, the handleChange function takes the event object as an argument, and we can access the value of the input field using event.target.value.
