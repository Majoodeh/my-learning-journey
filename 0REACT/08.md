## Order of Spread Operator:

The order of the spread operator (`...`) is important when merging objects or arrays, as it determines which values take precedence in case of conflicts.

When using the spread operator to merge objects, properties from later objects will overwrite those from earlier ones if they share the same key.

`Overwriting`: If there are duplicate keys, the property that appears last will overwrite any that came before it.

### Example of Object Merging with Spread Operator:

```javascript
const obj1 = { a: 1, b: 2 };
const obj2 = { b: 3, c: 4 };
const mergedObj = { ...obj1, ...obj2 };
console.log(mergedObj); // Output: { a: 1, b: 3, c: 4 }
```

In this example, the property `b` from `obj2` overwrites the property `b` from `obj1` because `obj2` is spread after `obj1`.

## Differnce between {...obj} and {obj} inside array:

When you use `{...obj}` inside an array, you are spreading the properties of the object `obj` into a new object. This means that each property of `obj` becomes a separate key-value pair in the new object.

but when you use `{obj}` inside an array, you are simply adding the entire object `obj` as a single element in the array.

### Example:

```javascript
const obj = { a: 1, b: 2 };
const arrayWithSpread = [{ ...obj }];
const arrayWithoutSpread = [{ obj }];
console.log(arrayWithSpread); // Output: [ { a: 1, b: 2 } ]
console.log(arrayWithoutSpread); // Output: [ { obj: { a: 1,
// b: 2 } } ]
```

In this example, `arrayWithSpread` contains an object with properties `a` and `b`, while `arrayWithoutSpread` contains an object that has a single property `obj`, which itself is the original object.

## Computed Property Names

```JavaScript
const {name, value} = event.target;
//! 1st option
setFormData((prevData) => ({
  ...prevData,
  [name]: value
}));


or
//! 2nd option
setFormData((prevData) => ({
  ...prevData,
  name: value
}));

```

[name] vs name:
In the context of the code snippet you provided, `[name]` and `name` have different meanings when used as keys in an object.

- `[name]`: This syntax is used to create a computed property name in an object. It means that the value of the variable `name` will be used as the key for the property in the new object. For example, if `name` is `"username"`, then `[name]: value` will result in `"username": value` in the new object.
- `name`: If you were to use `name` without the square brackets, it would literally use the string `"name"` as the key in the object. So, it would create a property with the key `"name"` regardless of the value of the variable `name`.

- in short, `[name]` it will just change the key called `name` to whatever value is stored in the variable `name`, while `name` would always add a new key called `"name"`, and the value to it.
